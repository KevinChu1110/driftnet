No account
One command starts it. Nothing to sign up for.
Your pick of AI, or none
A free model on your computer (Ollama), a subscription you already have (Claude or Gemini CLI), or a paid API key (pennies). With none, links are still saved but wait unsorted, for you or an AI agent to sort.
One file to keep
Everything sits in a single file on your computer (SQLite), with one-click backups.
Open source

Start catching.

The quickest start: driftnet's page on your computer plus the Chrome extension. Free, and it needs Node.js 22.13 or newer.

Try the demo

  1. 1Start it on your computer

    Paste this into a terminal. Your browser opens driftnet's page at localhost:8787.

    Keep that terminal window open while you use driftnet. Want it to start at login? Run it from source (macOS / Linux).

    Never used a terminal? Step by step →

  2. 2Add the Chrome extension

    One click saves the page you are on, Threads and Instagram posts included. The card shows up on your driftnet page.

    Get it from the Chrome Web Store →

  3. +Optional: a group chat

    Drop links into LINE, Discord, Telegram or Slack. Connecting a chat is an extra setup step (a bot of your own), so do it once the basics work.

    How to connect a chat →

  4. Or let your AI agent do it: paste this sentence into Claude Code, Cursor, Codex or any agent that can run commands on your computer.
