## 名稱
driftnet

## 簡短說明（上限 132 字）
把你正在看的貼文（內文、留言、連結，登入後才看得到的也行）送進你自己的 driftnet。支援 Threads、X、Instagram。

（這就是 manifest 的 `description`，所以同時是商店摘要。）

## 類別
工作效率

## 詳細說明

driftnet 會接住你滑到的連結，整理成你和你的 AI agent 都能搜尋的清單，資料在你自己手上。
這個擴充功能就是瀏覽器裡的「送出」按鈕。

很多頁面對匿名抓取一片空白：Facebook 圖片貼文、Threads 回覆、真正連結藏在留言裡的 Instagram
reels。擴充改送**你登入後自己看到的**內容：

- 展開「查看更多」；貼文只寫「連結在留言」時，會幫你打開留言去找。
- Threads：貼文、作者、引用的貼文、最多 20 則回覆，以及其中的連結。
- X / Twitter：把 t.co 短網址還原成真正目標的推文、引用推文、卡片連結，以及作者自己串的討論串。
- Instagram：說明、作者、前幾則留言和其中的連結。
- 去掉轉址包裝（l.facebook.com、l.instagram.com、l.threads.net、Google），清單拿到的是真正網址。

三種送法：工具列按鈕（整頁）、對連結按右鍵（該連結連同周圍貼文）、對選取的文字按右鍵（只送那段）。

預設就私密：只有你按下時才讀取該分頁，只送到你設定的 driftnet 伺服器（預設是你電腦上的
localhost:8787），沒有分析、不用註冊、不追蹤。

需要有一台 driftnet 伺服器（免費、MIT 授權）：https://github.com/KevinChu1110/driftnet

## 單一用途
把使用者選定的網頁、連結或選取的文字，送到使用者自己的 driftnet 伺服器，存進個人清單。

## 權限用途說明

| 權限 | 為什麼需要 |
|---|---|
| `activeTab` | 只在使用者按下的當下，讀取被按的那個分頁（工具列按鈕或右鍵選單），不需要對網站的廣泛存取。 |
| `scripting` | 使用者按下後，在該分頁執行頁面讀取程式：展開「查看更多」、打開留言、擷取文字與連結。 |
| `contextMenus` | 加入右鍵選單「把連結／選取內容／這頁送到 driftnet」。 |
| `storage` | 把使用者的設定（伺服器位址、選填的 token）存在自己的電腦，以及給彈出視窗顯示的最近一次送出結果。 |
| 主機存取 `http://localhost/*`、`http://127.0.0.1/*` | 把頁面送到使用者電腦上的預設 driftnet 伺服器。 |
| 選用主機存取（`https://*/*`、`http://*/*`） | 不會自動授予。使用者若把擴充指向遠端 driftnet 伺服器，設定頁只會就那一個位址詢問授權。 |

遠端程式碼：沒有。所有程式都在套件內。

## 資料使用揭露（隱私權做法分頁）

收集的資料類型，只勾：
- **網站內容**（使用者選擇送出的頁面之文字、圖片、連結）。

其餘（個人識別資訊、健康、財務、驗證資訊、個人通訊、位置、瀏覽記錄、使用者活動）一律不收集。
使用者可能填入的 token 只存在本機，並只以 `Authorization` 標頭送到使用者自己的伺服器；若後台詢問
傳輸中的憑證，請申報為**驗證資訊**，並說明是使用者自己提供、存在本機、只送到使用者自己的伺服器。

三項聲明（全部勾選）：
- 我不會在核准的使用情境之外，向第三方出售或傳輸使用者資料。
- 我不會將使用者資料用於與項目單一用途無關的目的。
- 我不會將使用者資料用於判斷信用度或放款。

白話回答：
- 收集什麼？使用者按下的那一個分頁的文字、標題、網址和連結（Threads、X、Instagram 另含畫面上看得到的回覆／留言）。
- 何時？只在使用者按工具列按鈕或右鍵選單的當下。
- 送去哪？只送到使用者設定的伺服器位址（自己的 driftnet 伺服器）。開發者什麼都收不到。
- 分析／遙測／廣告？都沒有。
