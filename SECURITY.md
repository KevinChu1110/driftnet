# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- **GitHub:** [Report a vulnerability](https://github.com/KevinChu1110/driftnet/security/advisories/new) (private advisory), or
- **Email:** guanrung1110@gmail.com

Include what you found, how to reproduce it and the version (`npx driftnet --version`). You'll get a reply within a few days, and a fix is released as soon as it's ready, with credit if you want it.

## Supported versions

Only the latest release gets security fixes. Upgrade with `npx driftnet@latest`.

## Scope

driftnet runs on your own machine. Reports about the server, the MCP server, the chat bots, the web page, the Chrome extension, the npm package and the Docker image are all in scope. See [Where your data goes](README.md#where-your-data-goes) for what driftnet sends where.
